:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Saiba o que há de novo em soluções para SAP.



[[12-august-2026]]
== 12 de agosto de 2026

Nova solução  https://docs.netapp.com/us-en/netapp-solutions-sap/backup/hana-sc-vmfs-asar2-smas-introduction.html["Proteção de dados SAP HANA com o SnapCenter usando VMware VMFS e SnapMirror active sync no NetApp ASA R2"^]. As melhores práticas para proteção de dados usando o SnapCenter para sistemas HANA executados em VMware com datastores usando VMFS e LUNs armazenados em sistemas NetApp ASAr2 usando o SnapMirror active sync estão descritas neste documento.



[[05-august-2026]]
== 05 de agosto de 2026

A nova solução  https://docs.netapp.com/us-en/netapp-solutions-sap/backup/hana-sc-bare-metal-asar2-scope.html["NetApp SnapCenter para SAP HANA em servidores bare metal com NetApp ASA systems"^] fornece as melhores práticas para a proteção de dados do SAP HANA com a NetApp SnapCenter, abrangendo diretrizes de configuração e operação do SnapCenter para proteger sistemas SAP HANA em sistemas ONTAP ASA com servidores bare metal.



[[26-february-2026]]
== 26 de fevereiro de 2026

Solução https://docs.netapp.com/us-en/netapp-solutions-sap/lifecycle/sc-copy-clone-introduction.html["Automatizando as operações de clonagem e cópia do sistema SAP HANA com o SnapCenter"] atualizada para abranger a criptografia do volume SAP HANA com armazenamento local seguro (LSS).

Solução atualizada https://docs.netapp.com/us-en/netapp-solutions-sap/backup/hana-sc-generic-scope.html["Backup e recuperação do SAP HANA com o SnapCenter"] para abranger a criptografia do volume SAP HANA com armazenamento seguro local (LSS), bem como novas configurações suportadas.



[[02-december-2025]]
== 02 de dezembro de 2025

Nova solução:link:https://docs.netapp.com/us-en/netapp-solutions-sap/backup/hana-sc-generic-scope.html["Backup e recuperação do SAP HANA com o SnapCenter"^]

Esta solução fornece as melhores práticas para proteção de dados SAP HANA com o NetApp SnapCenter, abrangendo diretrizes de configuração e operação do SnapCenter para proteger sistemas SAP HANA em sistemas ONTAP AFF e ASA , Azure NetApp Files e Amazon FSx para ONTAP.
